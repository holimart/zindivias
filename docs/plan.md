# Plan

The active plan is model-first under [`submission-policy.md`](submission-policy.md).
All information-probe uploads are cancelled; the former leaderboard-probe plan
is retained only as a historical archive. No labels are available, so model
candidates must be justified by challenge-provided features, organizer
methodology and public research, with deterministic local invariants instead
of a fabricated holdout score.

## Priority order

1. Model/estimator rows: Overture route-reference transport; facility-miss POI
   (after category audit); building and establishments levels; route-definition
   sensitivity; water/zero-population edge cases; then assemble a v2 model
   candidate with model-derived levels and no LB calibration.
2. Methodology and discovery writeups, scorecard reflection and literature
   review after the model mechanisms are documented.
3. Optional feature-sensitivity work only after the core estimator; final-two
   selection applies only to finished model candidates.

Any permitted live evaluation requires a written hypothesis against the current
best scored candidate (P4 public RMSE 0.091440198), passing invariants, operator
authorization, and the shared two-per-day submission gate. No upload is queued
by this plan.
